70% sampah di Indonesia tidak terpilah di sumber. Di Semarang, bank sampah menolak sampah campur, TPA Jatibarang overload.
ReWaste Abstrak mengubah data sampah jadi seni abstrak generatif. Setiap jenis sampah punya warna:
- Organik = Hijau
- Anorganik = Biru  
- B3 = Merah
- Campur = Abu-abu abstrak (noxious-troll)

Foto sampah -> AI -> warna abstrak -> tau tempat buangnya.

## What it does - Abstrak Edition

Foto sampah dalam 5 detik -> jadi lukisan abstrak + lokasi buang.
